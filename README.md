# Airlock Launcher

Лаунчер для Space Station 14: список серверов, аккаунты, загрузка контента и запуск игры.
Форк [SimpleStationLauncher](https://github.com/Simple-Station/SimpleStationLauncher), который, в свою
очередь, вырос из [лаунчера Space Wizards](https://github.com/space-wizards/SS14.Launcher).

> Игру делают [Space Wizards Federation](https://github.com/space-wizards/space-station-14) и сотни
> участников сообщества. Этот репозиторий — только лаунчер.

## Что умеет сверх обычного лаунчера

**Игра и серверы**

- Оповещение о новом раунде: следит за избранными серверами и показывает карточку, когда сервер
  возвращается в лобби (или набирает заданное число игроков).
- Личные заметки к серверам — чтобы помнить, чем один «Station 14 RU #3» отличается от другого.
- Состояние раунда в списке: «Лобби», «Идёт раунд 1ч 23м», «Конец раунда». Время считается в UTC,
  поэтому не уезжает на величину часового пояса.
- Автозаход на последний сервер при запуске (по желанию).
- Пустой список серверов объясняет причину: сколько хабов ответило из скольких.

**Сеть и блокировки**

- [zapret](https://github.com/Flowseal/zapret-discord-youtube) в комплекте: при первом запуске
  лаунчер предлагает оставить его или удалить. Домены игры дописываются в пользовательский список
  самого zapret, его собственные файлы не трогаются. Нужны права администратора — это драйвер
  фильтрации трафика.
- Проверка сети: за десять секунд опрашивает хабы, серверы аккаунтов, CDN движка и GitHub и
  показывает, какие хосты медленные или заблокированы.
- Загрузка движка переключается на зеркало, если хост из манифеста замолчал, а загрузка контента
  больше не висит вечно при молчащем сервере.

**Редактор персонажа**

- Отрисовка персонажа по данным выбранного форка: расы, маркировки, цвета, должности с их формой.
- Имена рас, маркировок и должностей берутся из локалей самого форка на языке лаунчера.
- Сохранение и загрузка персонажа в формате игры (`data/CHARACTERS/*.yml`), галерея всех персонажей
  с компьютера, случайный персонаж, экспорт PNG.

**Интерфейс**

- 14 тем оформления, включая светлую, и фоновая картинка с настройкой яркости и затемнения.
- Три полных языка: русский, английский, польский.
- Вкладка с вики и гайдами, просмотр скриншотов, статистика наигранного, конвертер валют.
- Перенос избранного, хабов и скачанного контента из другого лаунчера SS14.

## Где лежат данные

`%APPDATA%\Airlock Launcher` — настройки, аккаунты, персонажи; `%LOCALAPPDATA%\Airlock Launcher` —
скачанный контент игры (несколько гигабайт). Лаунчер никогда не делит эти папки с другим
лаунчером SS14, поэтому установленный рядом официальный лаунчер ничего не теряет.

## Сборка

Коротко: `python publish.py windows --x64-only`. Требования, подводные камни и способы собрать
только часть — в [BUILDING.md](BUILDING.md).
